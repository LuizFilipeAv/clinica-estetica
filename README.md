# Sálvia — clínica de estética fictícia

Site de portfólio para uma clínica imaginária, criado com React, TypeScript e Vite. A experiência apresenta cuidados faciais e corporais e uma simulação de agendamento. Nenhum horário é reservado e nenhum dado é enviado.

## Executar localmente

Requer Node.js compatível com o Vite 7 (20.19+ ou 22.12+).

```bash
npm install
npm run dev
```

Abra o endereço informado no terminal. Para validar o projeto:

```bash
npm test
npm run build
```

As imagens foram criadas para este projeto; seus prompts e informações de origem estão em `docs/assets.json` e `docs/prompts/`. Os originais ficam em `assets/originals/`, e as versões otimizadas usadas pelo site ficam em `public/images/`.

Sálvia, seus serviços e os horários exibidos são fictícios. Antes de adaptar o projeto para uma clínica real, substitua o conteúdo e conecte o agendamento a um serviço apropriado.
